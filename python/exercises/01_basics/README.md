# 01_basics：Python 基础语法

本目录是 Python 入门练习，覆盖变量与数据类型、运算符、条件与循环，
以及列表 / 元组 / 字典 / 集合等基础内容。所有脚本都用固定演示数据代替
`input()`，可以直接运行、不会阻塞。

## 文件说明

| 文件 | 对应练习 |
| --- | --- |
| `01_variables_and_flow.py` | 变量、数据类型、运算符、类型转换、条件判断、for / while 循环 |
| `02_camp_registration_report.py` | 夏令营报名分析：解析凌乱字符串、总人数、项目热度排序、按编号查询 |
| `03_workout_reminder.py` | “智能训练提醒”规则引擎：按优先级判断今天该做什么训练 |
| `04_data_structures.py` | 列表、元组、字典、集合的常用操作与推导式 |

## 运行命令

在仓库根目录执行（退出码 0 表示运行正常）：

```bash
python python/exercises/01_basics/01_variables_and_flow.py
python python/exercises/01_basics/02_camp_registration_report.py
python python/exercises/01_basics/03_workout_reminder.py
python python/exercises/01_basics/04_data_structures.py
```
